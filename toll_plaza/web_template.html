RL architecture

Environment
(4 toll lanes, ETC) ↓ Observe State
queue per lane (0..7) ↓ RL Agent (Q-Learning)
Q-table 4096 × 4 ↓ Select Action
dispatch vehicle to lane ↓ Toll Plaza
booths serve vehicles ↓ Calculate Reward
r = −Σ queue length ↓ Update Q-table
Q(s,a) += α(r + γ max Q' − Q) ↓ Next State
repeat Q-learning cycle: off-policy, bootstraps from max₁ Q(s′,a′)
